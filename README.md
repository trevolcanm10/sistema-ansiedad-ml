# 📱 Sistema Inteligente de Detección de Riesgo de Ansiedad

## 📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación móvil que permite detectar de manera temprana el riesgo de ansiedad en estudiantes universitarios mediante el uso de técnicas de Machine Learning.

El sistema recopila información relacionada con factores psicológicos, académicos y de estilo de vida, procesándolos para estimar el nivel de riesgo y generar recomendaciones personalizadas.

---

## 🎯 Objetivo General

Desarrollar una aplicación móvil que evalúe el estado emocional de los estudiantes y proporcione:

* Clasificación del nivel de riesgo de ansiedad (Bajo, Medio, Alto)
* Recomendaciones personalizadas
* Seguimiento del progreso en el tiempo

---

## ⚙️ Funcionalidades Principales

* Registro de usuario
* Evaluación mediante cuestionarios (PHQ-9, GAD-7 y otros indicadores)
* Predicción del riesgo de ansiedad usando Machine Learning
* Visualización de resultados
* Generación de recomendaciones personalizadas
* Historial y seguimiento del progreso
* Notificaciones inteligentes
* Exportación de datos para investigación

---

## 🧠 Tecnologías Utilizadas

* **Frontend:** Flutter (MVVM)
* **Backend:** Flask - Python (Arquitectura tipo MVC)
* **Base de Datos:** MySQL
* **Machine Learning:** Python

---

## 🏗️ Arquitectura del Sistema

Flutter (Aplicación móvil - Vista)
↓
Flask API (Lógica de negocio y controladores)
↓
Base de Datos (Modelo) + Motor de Machine Learning

## 📂 Estructura del Proyecto
